你问的四个站点我去逐个实测了。结论是：CFTC 是本轮唯一真正有价值的新数据源， vixcentral 和 TradingView 只能取当期快照（做交叉验证可以，做历史回测不行）， investing.com 的历史接口对指数类的 VIX 完全不开放。但顺藤摸瓜在 CBOE 官方 CDN 上又挖到 23 个波动率指数文件， 这批数据让「期限结构」从原来的 1 个斜率变成 4 个斜率，还多出 VVIX 和 SKEW 两个指标。

五条核心结论
  1. CFTC 拿到两套口径，其中 TFF 口径是新的。Legacy 把持仓分成商业/非商业，太粗； TFF 分成 Dealer（交易商）、Asset Manager（资管）、Leveraged Funds（杠杆基金）、Other Reportables 四类， 能直接识别「谁在做空波动率」。答案是杠杆基金：82.9% 的周数净空，均值 −49,309 张——这是 VIX 期货 contango 下做空波动率 carry 的直接证据。
  2. 「空头拥挤就要崩」这个直觉，数据不支持。杠杆基金空头拥挤度分位 >90% 的 202 周里， 随后 52 周 VIX 涨超 25% 的概率只有 16.0%，低于基准 27.45%；13 周 SPX 跌超 5% 的概率 10.89%，也低于基准 12.00%。 方向与先验相反。
  3. 为什么不能据此交易：控制当期 VIX 后，拥挤度的解释力消失。预测 13 周 SPX 时，拥挤度系数 t 值只有 0.15， 而 VIX 自身 t=4.90。且超额在低 VIX 组 +6.77pp、高 VIX 组 −2.38pp，符号翻转——超额来自 VIX 均值回归，不是持仓。
  4. CBOE 官方新增 4 档期限结构，斜率方向高度一致。短端（VIX/VIX9D）、中端（VIX3M/VIX）、长端（VIX6M/VIX3M）、 全曲线（VIX6M/VIX9D）四条斜率，全部呈现「越陡、未来一年越差」：分位 0-10% 组的 12 个月收益 16.6%~18.9%， 分位 90-100% 组只有 7.3%~11.5%。
  5. VVIX 与 SKEW 补上了一块空白。VVIX 与「未来 21 日 VIX 变化」的相关是 −0.2753（负号意味着 VVIX 越高、VIX 随后越倾向回落）， 而 SKEW 与未来收益几乎无关（−0.0114）——它度量的是左尾定价的贵贱，不是方向。

另外必须说明一个口径变化：数据已经推进到 2026-11-09。11-06 那天 VIX 25.64、期限倒挂 +4.23%， 到 11-09 已经回到 VIX 19.92、期限结构 −4.46%（正常 contango），SPX 两天涨 2.35%。 所以上一份报告里「当前读数」那一节的部分结论需要按新数据更新，本报告第七章给出对照。

一、逐个站点实测结果

测试环境：Windows / Python 3.12 / urllib（无 requests、无 yfinance）。 本机 github.com:443 与 Yahoo 直连被阻断，但 127.0.0.1:7897 代理可用； CFTC 官网与 CBOE CDN 可直连。下面逐站说明。

1.1 CFTC 官网 可用

CFTC 有两条路：一是官网的年度压缩包 cftc.gov/files/dea/history/deacot2026.zip（直连 200，1993 年起按年分文件）， 二是更现代的 Socrata 公开报表 API publicreporting.cftc.gov。后者能按合约名过滤、分页拉全量，明显更好用。

我们拉了两个数据集，都是 VIX FUTURES - CBOE FUTURES EXCHANGE 这一个合约：

表 1-1 CFTC 两个口径的 VIX 期货持仓数据
数据集Socrata ID行数覆盖区间列数分类口径
Legacy - Futures Only6dca-aqww1,120 周2004-07-27 ~ 2026-11-03133 列商业 / 非商业 / 非报告 三分
TFF - Futures Onlygpe5-46if1,024 周2006-08-29 ~ 2026-11-0390 列交易商 / 资管 / 杠杆基金 / 其他 四分
三条必须知道的限制： ① 周频——每周二收盘的持仓，周五 15:30 ET 才公布，有 3 天滞后； ② 我们验证过：1,120 周里有 1,038 周的报告日+3 个交易日正好落在周五，说明这个滞后规则是稳定的； ③ TFF 起点是 2006-08 而不是 2004，比 Legacy 短两年。

几个实测中踩到的坑，写下来免得重复：

  • Socrata 的 $order 参数里如果有空格会触发 URL can't contain control characters，必须 urllib.parse.quote 编码。
  • 有些数据集（ubmb-6exi / 98ig-3k9y / 8jj7-5vf4 / dw8z-x6ih）返回 403「no row or column access to non-tabular tables」——这是 Combined 口径的视图表，不是可查询的原始表。
  • Legacy 里那个列名是 noncomm_postions_spread_all，postions 少一个 i，是 CFTC 自己的拼写错误，按正常拼写取列会 KeyError。

1.2 vixcentral.com 部分可用

这个站最有价值的是 VIX 期货完整期限结构。页面本身直连 200，数据在三个内部 ajax 接口里：

表 1-2 vixcentral 的三个内部接口

/ajax_updateGET，无参数VIX 期货当期 8 个到期月的买卖价/结算价可用，返回 15 行 JSON 数组，60 秒刷新
/ajax_historical?n1=YYYY-MM-DDGET，逐日指定交易日的历史期限结构可用但只能逐日查，且部分日期返回 "error"

我们做了 40 个交易日的均匀抽样（2005-01-03 ~ 2026-03-31），可用率 95%（38/40）， 返回格式是 [到期月序号, M1, M2, …, M9]，例如 2020-03-16 是 [3, 72.625, 59.15, 44.875, …]——典型的深度倒挂。

但有一个致命的数据质量问题。我们把 M1（近月期货）与同期 VIX 现货逐月对比， 发现 2006 年至 2007 年 2 月之间，M1 全是 110~150 量级，而 VIX 现货只有 11~16，偏差高达 900%~990%：

站点可以访问（走代理），VIX 页面 /indices/volatility-s-p-500 返回 1.07 MB HTML， 从中能抠到 instrumentId = 44336。但核心的历史数据接口打不通：

作为对照，同一个接口用标普500 的 id=8839 是完全可用的（返回 OHLCV 数组）。 所以不是接口坏了，是指数类品种（尤其 VIX）没有对公开 API 开放历史数据。 另外 api.investing.com/api/search/v2/search 只返回文章不返回品种，也帮不上忙。 结论：investing.com 这条路放弃，标普500 我们本来就有更好的源。

二、CFTC：本轮最有价值的发现

2.1 两套口径：Legacy 与 TFF

CFTC 对同一份持仓有多个分类口径。Legacy 是最老的，只分商业/非商业；TFF 是 2006 年为金融期货新设的， 把参与者分成四类，对波动率这种「谁在卖保险」的问题更有解释力：

表 2-1 TFF 四类交易者的行为与实测结果
TFF 分类典型行为本样本实测
交易商 Dealer/Intermediary做市商，双边报价，通常净空波动率77.6% 周数净多
资管 Asset Manager/Institutional养老金、共同基金，买保护的主力83.3% 周数净多
杠杆基金 Leveraged Funds对冲基金、CTA，做空波动率 carry 的主力82.9% 周数净空，均值 −49,309 张
其他可报告 Other Reportables其余达到报告门槛的—
这里要修正一个常见误解。很多资料说「商业持仓通常是空头」， 但实测 VIX 期货的 Legacy 商业净持仓均值是 +46,934 张，是净多；TFF 的交易商同样净多。 真正的净空方是杠杆基金。原因不难理解：VIX 期货长期 contango， 卖近月买远月（或单纯卖空）能吃到展期收益，这是典型的 carry 交易，杠杆基金是主要玩家。

2.2 谁在做空波动率

图中蓝线是杠杆基金净持仓（负值 = 净空），红区是「空头拥挤度」的滚动 3 年分位。 可以看到一个很稳定的形态：市场平静时杠杆基金不断加空（蓝线下行、红区上升）， 一旦 VIX 跳升就急速回补（蓝线飙升、红区骤降）。2008、2015-08、2018-02、2020-03 都是典型。

这个形态本身很有说服力，但能不能拿来做买卖点，是另一回事——下面用数据检验。

2.4 为什么它不能单独当信号

上面的分档看着有单调性，但有一个致命问题：持仓拥挤度和当期 VIX 水平高度共线。 市场平静时 VIX 低、杠杆基金加空；VIX 高时回补。所以「拥挤度高」几乎等价于「VIX 低」， 而 VIX 低本身就对应未来一年收益较好（原报告第三章已经证明）。

我们做了回归检验，把当期 VIX 作为控制变量放进去：

顺便说一句口径比较：净头寸与未来 52 周 SPX 的相关系数，杠杆基金 −0.30、资管 +0.24、交易商 +0.24， Legacy 只有 −0.18。TFF 的信息量确实高于 Legacy，Legacy 与杠杆基金的相关是 +0.71，本质是粗代理。

三、vixcentral：期货期限结构

vixcentral 的 /ajax_update 返回当期 VIX 期货的完整期限结构，这是 CBOE 的指数文件里没有的 （CBOE 给的是不同期限的指数，vixcentral 给的是期货合约价格）。两者有区别： 期货价格含展期与风险溢价，理论上比指数更能反映实际可交易的定价。

有意思的是 M1（20.05）低于 M2（19.55）？不是——按列看是 M1=20.05、M2=19.55，近月略高于次月， 但 M3 以后重新上行。这是一个「驼峰型」的短端结构，说明市场认为下个月的风险比这个月低、但 1 月以后风险回升。 这种形态用单看 VIX/VIX3M 是看不出来的。

但我们最终没有用 vixcentral 做历史回测，三个原因：

  1. 没有批量接口，只能逐日 GET；20 年要约 5,000 次请求，单次 1~3 秒，不现实。
  2. 可用率 95%（40 个抽样日里 2 个返回 error），有缺失但不致命。
  3. 2007 年 3 月以前数据明显错误（M1 与 VIX 现货偏差 900%+），可用起点被压到 2007。

而 CBOE 的 VIX9D/VIX3M/VIX6M 指数文件能覆盖 2009 年以后， 虽然口径是「指数」不是「期货」，但连续、免费、无缺失，做研究反而更合适。 vixcentral 的正确用法是「看当期的期货曲线形态」，不是「做历史回测」。

五、VVIX 与 SKEW

这两个指标此前完全没有纳入过。它们度量的都不是「波动有多大」，而是「波动率的波动」和「尾部定价的偏斜」。

5.1 VVIX：波动率的波动率

VVIX 是 VIX 期权的隐含波动率，简单说就是「市场对标普波动的分歧程度」。 它与 VIX 的相关只有 0.4251，说明它确实携带独立信息。

VVIX 的独特之处在于它预测的是「VIX 往哪走」，不仅仅是收益。
  • VVIX > 130（极动）：135 天，未来 21 日 VIX 平均下降 10.67 点——这是全部指标里最强的 VIX 回落信号； 同时未来 1 个月 SPX +5.01%、胜率 83.46%，3 个月 +8.47%。VVIX 极高时买，是很好的短期买点。
  • VVIX < 80（极静）：933 天，未来 12 个月只有 +3.71%、胜率 71.08%——全表最差。 「市场太安静」确实是个值得警惕的信号，而这个信号 VIX 本身给不出来（VIX<13 后一年反而是 +12%）。
这是一个真正的新发现：VIX 低不需要担心，但 VVIX 低需要。 两者的区别是：VIX 低只说明大家都觉得没事；VVIX 低说明大家连「会不会出事」都不讨论了。

相关系数验证了这个不对称性：VVIX 与未来 21 日 VIX 变化的相关是 −0.2753， 而 VIX 自身与未来 VIX 变化的相关接近 0（均值回归的必然）。也就是说 VVIX 在「VIX 拐点」上有真正的领先性。

八、局限与未完成的部分

数据本身的天花板

  • 期限结构的历史太短。VIX9D 从 2011、VIX6M 从 2008、VIX3M 从 2009 才有。 第四章的所有结论样本起点是 2011-01，只有 3,986 个交易日、15 年， 没有覆盖 2008 金融危机。这是数据决定的，不是选择。
  • CFTC 持仓只有 20 年、周频、3 天滞后。Legacy 1,120 周、TFF 1,024 周，独立事件更少。 第二章的「52 周 t 值」看着有 3.72，但那是重叠样本，有效自由度远低于名义周数。
  • VVIX 只有 2006 年以后（5,144 天），且 2006 年前几个月数据有异常（首个值 71.73 次日跳到 15.71）， 用法上以分位而非绝对值更稳妥。
  • vixcentral 的期货曲线无法批量回溯。只能看当期，或手工查单日。

方法上的限制

  • 所有新指标都是样本内描述。VVIX>130、SKEW 组合、四条斜率，都是先看到数据再总结规律， 存在数据窥探（data snooping）风险。真正的检验需要样本外，而样本长度不够切。
  • 没有计入交易成本与展期损益。第二章若真按 COT 信号做多空，还要考虑期货展期成本， 那个成本在 contango 结构下对空头是有利的（正是 carry 的来源），但对结论方向影响不大。
  • 三源比对只在当期做过。TradingView 没有历史，所以「VIX 与 TradingView 一致」只能证明今天一致， 不能证明历史上也一致。历史序列的可信度仍依赖 CBOE 与 Yahoo 的双源比对。
  • 2026-11-09 只有一天数据。表 7-1 的对照是「单点 vs 单点」，不能当作趋势。

没做成的事

  • investing.com 的 VIX 历史。接口全部 500，没有绕过的办法（试过 8 个 instrumentId、5 种 period）。
  • TradingView 的历史 K 线。symbol-search 403、datafeed 需登录，没有免费途径。
  • CFTC 的 Combined（期货+期权）口径。对应的 4 个数据集都是 403 不可查询视图， 只有 Futures Only 能用。这对 VIX 影响不大（VIX 期权持仓另有来源），但仍是个缺口。
